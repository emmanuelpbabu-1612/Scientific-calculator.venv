
# 🔢 Scientific Calculator

A GUI-based Scientific Calculator that performs both **basic** and **advanced mathematical operations**. Ideal for students, developers, and beginners learning GUI applications with Python.

## ✅ Features

* ➕ Addition, ➖ Subtraction, ✖ Multiplication, ➗ Division
* √ Square Root
* ^ Exponent / Power
* % Modulo
* ( ) Parentheses handling
* sin, cos, tan
* log, ln
* π, e
* Clear & Backspace buttons
* Keyboard support *(if added)*

## 🛠️ Tech Stack

* **Language:** Python
* **GUI Framework:** Tkinter / PyQt / CustomTkinter *(replace with yours)*
* **Platform:** Windows / Mac / Linux

## 🚀 How to Run

```bash
# 1. Clone the repository
git clone https://github.com/your-username/scientific-calculator.git

# 2. Open the project folder
cd scientific-calculator

# 3. Run the script
python calculator.py
```
